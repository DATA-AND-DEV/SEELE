# SEELE 0.19.0

## Novidades

- Nova interface no aplicativo, na web e no celular: telas redesenhadas, ícones no lugar de textos, cartões de pessoa simples e um modal para ver cada pessoa.
- Perfis oficiais dentro do SEELE: nome, cor e imagem do perfil passam a ser do produto, e não mais de um MOD. Ao atualizar, os perfis do MOD PERFIS são migrados; se alguma imagem não puder vir, o app avisa.
- Avisos sonoros para chamadas, sala de voz, conexão e portaria.
- API 8 dos MODs: um MOD pode hospedar um servidor de jogo no computador do anfitrião, com a aprovação dele. O anfitrião vê o que o MOD pede antes de aceitar, e o jogo para quando o servidor do SEELE para.
- Hospedar mostra uma tela de carregamento enquanto o servidor sobe.
- Quem espera a aprovação do anfitrião vê que está só esperando. Sair dessa tela, ou fechar a janela, pede confirmação.
- Modais de MOD seguem o estilo dos modais do app, e a barra de controles fica sempre livre.

## Correções

- Furos de canal, senha e volume encontrados na revisão de segurança da 0.19 foram fechados.
- O microfone que falha não derruba mais a escuta; o pedido de microfone vem ao entrar na chamada.
- Ao reabrir o app depois de uma queda, um jogo que ficou para trás é salvo e parado antes de qualquer servidor subir de novo.

## Validação

- Testes de protocolo, servidor, core, ponte, conformidade dos MODs e interface passaram, assim como as bancadas de navegador do CI em Chromium e WebKit.
- Hospedagem pela API 8 exercitada no app de verdade com Forge e NeoForge, no Mac e no Windows: subir, entrar, salvar, reiniciar o servidor e fechar o app com o jogo de pé.

## Limitações

- A hospedagem de jogo não foi testada entre duas casas diferentes, nem com um cliente Forge entrando por conta Microsoft.
- Linux e Quilt não foram exercitados com a API 8. MODs de navegador que abrem porta não foram testados.
- No Windows, encerrar a sessão do sistema dá ao jogo só cerca de 1 segundo para salvar antes de o Windows fechá-lo. Pare o servidor antes de sair da sessão.
- O congelamento ao compartilhar a tela do Mac numa conversa pessoal continua sem correção.
- Os pacotes desta versão são macOS Apple Silicon e Windows x64; Linux não foi empacotado nesta rodada.
- Não há TURN/relay. Algumas combinações de redes podem impedir a conexão direta.
