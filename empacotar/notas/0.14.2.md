> ### A API de MODs subiu para 5, e os MODs que você tem continuam funcionando
>
> Um pacote de API 3 ou 4 continua sendo executado por este build — a
> conferência aceita as três. **Nada do que está instalado para de funcionar ao
> atualizar.**
>
> O que a API 5 traz é o caminho das imagens: elas deixam de atravessar o
> controle em fragmentos de texto e passam pelo fluxo de volume, o mesmo que os
> anexos já usavam. Quem escolhe o arquivo é o seletor do sistema, e os bytes
> não passam pelo motor de scripts do MOD em momento nenhum.

> ### O catálogo passa a oferecer a versão que a **sua** versão entende
>
> Até aqui a tela de MODs oferecia sempre a última versão publicada, sem olhar
> que API ela pede. Funcionava todo dia menos o seguinte a uma subida de API:
> quem não tinha atualizado via a versão nova, apertava instalar, e recebia uma
> recusa — **sem caminho de volta** para a versão que funcionava para ele, que
> continuava publicada logo acima na mesma lista.
>
> Agora a tela escolhe a última versão cuja API este build sabe executar. Se
> você está numa versão anterior do SEELE e um MOD publicou algo mais novo, você
> continua vendo e instalando a última que serve para você.
>
> **Isto conserta o futuro, não o presente.** A escolha que decide é a do
> aplicativo que está instalado, e o conserto vive nele. Quem estiver na v0.14.1
> ou antes ainda vai ver a versão mais nova oferecida até atualizar.
