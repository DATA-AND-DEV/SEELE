# F7 — A sala pessoal (Plano 5) e as hospedagens desacopladas (Plano 2): plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ligar pelo código. Quem tem o código de uma pessoa cola em CONECTAR, o app dela toca, ela atende ou recusa, e a ligação acontece na sala que roda no app dela, com até 6 pessoas. Para isso, o servidor que a pessoa hospeda passa a ficar de pé enquanto ela visita outro (Plano 2).

**Architecture:**
- **No servidor**, uma segunda `Hospedagem`, em memória e sem MODs, na porta 8385. Ela tem três peças:
  - o certificado Ed25519 feito da chave da pessoa;
  - uma `campainha` pura, com o tempo injetado;
  - o aperto de mão em três fases, que segura a conexão enquanto toca.
- **Em quem liga**, o `seele-core` confere o código **dentro do TLS** (`Esperada::Codigo`), localiza a pessoa pelo quarto e trata o `Tocando`.
- **Na casca**, uma faixa de toque do núcleo de confiança, o som tocado pelo Rust e a agenda.
- **O Plano 2** troca a vaga única de hospedagem por `Session.hospedagens`, com uma resposta só a «estou no meu servidor?».

**Tech Stack:**
- Rust: `seele-proto`, `seele-core`, `seele-server`, `seele-audio` (`cpal` 0.18), `seele-ffi`;
- `quinn` 0.11.11, `rustls` 0.23.45 com o provedor `ring`, `rcgen` 0.14.8, `ed25519-dalek` 3;
- a casca em JavaScript sem build (`apps/seele-app/ui/`), o Tauri 2.

- **TDD:** cada tarefa traz o teste que falha antes, a prova por reversão (desfazer o conserto e ver o teste falhar com a frase dele, depois restaurar e conferir com `git diff`), e um commit em português no estilo do `git log`, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

Teste de conformidade toma `let _vaga = vaga::minha();` na primeira linha. Se a orquestradora avisar de uma bateria em curso, **não rode conformidade**: compile com `--no-run` e anote no progress que ficou para depois.

  O aviso do linker `ld: duplicate -rpath` é ambiental.
- **Fronteiras:**
  - `crates/seele-proto` é da F1. Se uma tarefa precisar de algo no fio, ela para e volta à orquestradora;

## Achados desta leitura, para a orquestradora

Os quatro abaixo foram medidos no código, e não supostos.

**A1. A linha legada reabre o S2 e deixa um servidor 0.15 atender as ligações da pessoa.** **Decidido pelo dono em 08/10:** a 0.15.2 só assina desafios de exatamente 32 bytes, e quem escreve é a F6 em `linha/0.15`. O texto abaixo é o achado como foi mandado.
- O cliente da 0.15 assina o nonce cru que vier, de até 256 bytes:
  - a assinatura: `linha/0.15:crates/seele-core/src/client.rs:1974`, `signing_key.sign(&nonce)`;
  - o teto: `MAX_PROOF_LEN = 256`, em `control.rs:277`.
- A linha legada roda com **a mesma chave**: a F6 copia a `identity.key` para `dados/servidor-0.15`, e a tarefa 4b quer uma chave só por máquina.
- O que um servidor 0.15 malicioso, visitado pela linha legada, consegue fazer com isso:
  - **entrar como a pessoa num servidor 1.0.** Ele manda como nonce a mensagem do S2 inteira (`rótulo ‖ fp de X ‖ nonce de X`, 89 bytes), e repassa a assinatura a X. Se X for o servidor da própria pessoa, entra como Comandante;
  - **atender as ligações da pessoa.** Ele manda como nonce o conteúdo de um CertificateVerify do TLS 1.3 (130 bytes, cabe nos 256). O `ConfereCodigo` aceita a chave e a assinatura.
- **A medida que resolve:** todo servidor 0.15 manda exatamente 32 bytes (`NONCE_LEN = 32`, `linha/0.15:crates/seele-server/src/session.rs:57`, desde o primeiro commit). Uma 0.15.2 que **só assina nonce de 32 bytes** continua falando com todo servidor 0.15 de verdade, e nenhum dos domínios da 1.0 cabe em 32 bytes. Os tamanhos:
  - a prova do S2: 89;
  - o CertificateVerify: 130 ou 146;
  - um `TBSCertificate`: centenas;
  - o `MORO2`: o rótulo (17 bytes) e a chave (32) já passam de 32, antes dos outros campos.
- **A 0.15.2 ainda não foi publicada.** Conferido na API de releases: o último release é a `v0.15.1 · 54f542f94`. Então dá tempo.
- **A recomendação:** a 0.15.2 leva a regra dos 32 bytes, com o teste e a prova por reversão, no `linha/0.15`. Ela é obrigatória para que a identidade seja a mesma nas duas linhas, seja por cópia, seja pela 4b. A F7 a escreve se a orquestradora mandar.

**A2. Na sala, o primeiro atendido viraria o Comandante.**
- A sala não tem portaria: no lugar dela, tem a campainha.
- O dono só conecta na própria sala **ao atender** (spec de 23/09, «Atender, nesta ordem»). Até lá, o banco em memória não tem conta nenhuma.
- A primeira conta criada vira Comandante (`permissions::seat_the_arrival`). Então quem toca e é atendido entra **antes** do dono e fica com a sala.
- **Por isso o gancho da sala (tarefa 11) cria a conta do dono**, e não só o semeia na portaria. Um teste prova.

**A3. O DER do certificado da sala vira formato congelado.**
- O dono entra na própria sala por `127.0.0.1:8385`, e o pino do TOFU é por `host:porta`.
- Qualquer mudança no DER muda a impressão. Isso vale para o SAN, a validade, o número de série e o nome, e o dono leria «A CHAVE MUDOU» na própria sala.
- A tarefa 2 congela o SHA-256 do DER da semente de zeros num vetor.
- A recomendação para a tarefa 27: o dono entra na própria sala com `Esperada::Codigo(meu código)`, e não pelo TOFU.

**A4. Um pedido à F1: `seele_proto::transport::NOME_DA_SALA = "seele-sala"`.**
- O SNI `seele-sala` é o item 12 do §3, e o cliente (`seele-core`, tarefa 12) precisa dele.
- O `seele-core` não pode depender do `seele-server` (ADR 0002).
- A tarefa 2 o define em `seele-server/src/tls.rs`, e passa a reexportar o do `seele-proto` quando a F1 o puser. O valor está congelado pelo vetor do DER, então a troca não muda um byte.

**Números de ADR:** 0059, 0060 e 0061 são desta frente. O 0062 fica reservado para o ENC/2. Conferido em todos os branches `0.16/*`, `versao/0.16` e `linha/0.15`: o mais alto é o 0058.

```rust
//! A janela em que um estranho virava o Comandante de um servidor recém-criado.
//!
//! **O defeito, como foi lido em `4fc31e9c`.** `Hospedagem::iniciar` punha o
//! laço de aceitação no ar, e só **depois** o app semeava a portaria e admitia
//! quem hospeda. Num banco novo a portaria nasce desligada, e a primeira conta
//! criada num servidor vira a Comandante (`permissions::seat_the_arrival`).
//! Quem chegasse nesse intervalo entrava sem bater e ficava com o servidor.
//!
//! **O conserto** (D-seg-1 do spec da 0.16, a tarefa 4e do Plano 5, que entra
//! pelo Plano 2): `Hospedagem::iniciar` recebe o que fazer **antes de
//! aceitar**, e roda isso com o banco já aberto e o laço ainda parado. A ordem
//! deixou de depender de quem chama. É o desenho de `ba99007`, que a linha
//! 0.15 leva na 0.15.2.
//!
//! **As duas formas de banco.** Em arquivo é o servidor guardado; em memória é
//! a forma da sala pessoal, que sobe pela mesma porta (tarefa 4f). As duas
//! passam pelo mesmo `iniciar`, e a prova roda nas duas.
//!
//! **A prova tem duas metades.**
//!
//! 1. **A estrutural:** enquanto o gancho roda, um estranho tenta conectar, e
//!    a conexão **não** se estabelece. No quinn 0.11 o aperto de mão só anda
//!    quando o laço chama `accept`, então uma conexão estabelecida durante o
//!    gancho é a prova de que o laço já estava no ar. Esta é a metade que
//!    reprova com a ordem de antes.
//! 2. **A de quem usa:** depois, o estranho bate e fica de fora, e quem hospeda
//!    entra e é o Comandante.
//!
//! Por que a primeira metade não é «o estranho entrou durante a espera»: o
//! gancho roda com o banco travado, e a sessão do estranho precisa do banco
//! para criar a conta. A primeira tentativa desta prova, em `ba99007`, passou
//! revertida por isso. A conexão aceita não depende do banco, e é ela que diz
//! se o laço já estava no ar.

/// Um verificador que aceita qualquer certificado: o que está sob teste não é
/// o TOFU, e o certificado é o que este servidor acabou de gerar.
#[derive(Debug)]
struct AceitaQualquer(Arc<rustls::crypto::CryptoProvider>);

impl rustls::client::danger::ServerCertVerifier for AceitaQualquer {
    fn verify_server_cert(
        &self,
        _end_entity: &rustls::pki_types::CertificateDer<'_>,
        _intermediates: &[rustls::pki_types::CertificateDer<'_>],
        _server_name: &rustls::pki_types::ServerName<'_>,

    fn verify_tls12_signature(
        &self,
        message: &[u8],
        cert: &rustls::pki_types::CertificateDer<'_>,
        dss: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {

            message,
            cert,

        &self,
        message: &[u8],
        cert: &rustls::pki_types::CertificateDer<'_>,
        dss: &rustls::DigitallySignedStruct,
    ) -> Result<rustls::client::danger::HandshakeSignatureValid, rustls::Error> {

            message,

/// O que aconteceu com uma tentativa de entrar.
#[derive(Debug, PartialEq, Eq)]
enum Desfecho {
    /// O servidor mandou `Session`: a conta existe e está dentro.
    Entrou,
    /// O servidor encerrou o aperto de mão, com o motivo.
    Barrado(DisconnectReason),
}

/// A configuração de cliente de um par cru.
fn cliente() -> quinn::ClientConfig {
    let _ = rustls::crypto::ring::default_provider().install_default();
    let provider = Arc::new(rustls::crypto::ring::default_provider());
    let mut tls = rustls::ClientConfig::builder()
        .dangerous()
        .with_custom_certificate_verifier(Arc::new(AceitaQualquer(provider)))
        .with_no_client_auth();
    tls.alpn_protocols = vec![seele_proto::transport::ALPN.to_vec()];
    quinn::ClientConfig::new(Arc::new(
        quinn::crypto::rustls::QuicClientConfig::try_from(tls).expect("config do QUIC"),
    ))
}

/// A prova de identidade do S2: o rótulo, a impressão do certificado que o TLS
/// desta conexão aceitou e o nonce, montados por `seele_proto::assinatura`.
fn prova_amarrada(conexao: &quinn::Connection, nonce: &[u8]) -> Vec<u8> {
    let cadeia = conexao
        .peer_identity()
        .and_then(|identidade| {
            identidade
                .downcast::<Vec<rustls::pki_types::CertificateDer<'static>>>()
                .ok()
        })
        .expect("o TLS sempre entrega a cadeia do servidor");
    let impressao = seele_proto::transport::certificate_digest(
        cadeia
            .first()
            .expect("a cadeia tem um certificado")
            .as_ref(),
    );
    let nonce: [u8; 32] = nonce.try_into().expect("o desafio tem 32 bytes");
    seele_proto::assinatura::prova_de_cliente(&impressao, &nonce)
}

/// Um aperto de mão inteiro, sem convite, com a chave desta semente.
async fn tentar(endereco: SocketAddr, semente: u8) -> Result<Desfecho> {
    let mut ponta = quinn::Endpoint::client(SocketAddr::from(([127, 0, 0, 1], 0)))?;
    ponta.set_default_client_config(cliente());
    let conexao = ponta.connect(endereco, "localhost")?.await?;
    let (mut envio, mut recebe) = conexao.open_bi().await?;
    let chave = SigningKey::from_bytes(&[semente; 32]);
    frame::write(
        &mut envio,
        &ClientMessage::Hello {
            faixa: seele_proto::FAIXA,
            client: "par-cru".into(),
            nickname: format!("pessoa{semente:03}"),
            public_key: chave.verifying_key().to_bytes().to_vec(),
            join_secret: None,
            material_e2ee: None,
            apis_de_mod: Vec::new(),
        },
    )
    .await?;

    loop {
        match frame::read::<ServerMessage>(&mut recebe).await? {
            ServerMessage::Challenge { nonce } => {
                frame::write(
                    &mut envio,
                    &ClientMessage::Response {
                        proof: chave
                            .sign(&prova_amarrada(&conexao, &nonce))
                            .to_bytes()
                            .to_vec(),
                    },
                )
                .await?;
            }
            ServerMessage::Session { .. } => return Ok(Desfecho::Entrou),
            ServerMessage::Disconnecting { reason } => return Ok(Desfecho::Barrado(reason)),
            // Outro quadro do aperto de mão: segue lendo.
            _ => {}
        }
    }
}

/// Só o aperto de mão do QUIC, sem nenhuma mensagem do SEELE. Volta quando a
/// conexão se estabelece, o que só acontece com o laço de aceitação no ar.
async fn so_conectar(endereco: SocketAddr) -> Result<()> {
    let mut ponta = quinn::Endpoint::client(SocketAddr::from(([127, 0, 0, 1], 0)))?;
    ponta.set_default_client_config(cliente());
    ponta.connect(endereco, "localhost")?.await?;
    Ok(())
}

/// Uma porta livre nesta máquina, para o estranho saber onde bater antes de
/// `iniciar` devolver o servidor.
fn porta_livre() -> u16 {
    std::net::UdpSocket::bind("127.0.0.1:0")
        .and_then(|s| s.local_addr())
        .map(|e| e.port())
        .expect("uma porta livre")
}

fn chave_publica(semente: u8) -> [u8; 32] {

        .verifying_key()
        .to_bytes()
}

/// A janela, medida num banco desta forma.
async fn a_janela_fica_fechada(banco: Location) {

    let dono = seele_proto::transport::key_fingerprint(&chave_publica(DONO));
    let aceito_durante_o_gancho = Arc::new(AtomicBool::new(false));

            })

        seele_server::portaria::admitir_o_dono(persistence, &dono)

    .expect("subir");

        !aceito_durante_o_gancho.load(Ordering::SeqCst),
        "uma conexão foi aceita enquanto quem hospeda ainda semeava a portaria: \

        "um estranho entrou sem convite num servidor recém-criado: {desfecho_do_estranho:?}"

        tentar(endereco, DONO).await.expect("o dono conecta"),

        "quem hospeda não entrou na própria casa"

            .unwrap(),

        .unwrap();

        !permissoes
            .may(do_estranho.id, Permission::AdministerServer)
            .unwrap(),
        "o estranho ficou com o servidor"
    );
}
```

```rust
/// O começo da SPKI de uma chave Ed25519 em DER (RFC 8410, §4): a `SEQUENCE`
/// de fora, o algoritmo `1.3.101.112` e o `BIT STRING` de 33 bytes.
const SPKI_ED25519: [u8; 12] = [
    0x30, 0x2a, 0x30, 0x05, 0x06, 0x03, 0x2b, 0x65, 0x70, 0x03, 0x21, 0x00,
];

/// A chave Ed25519 crua de um certificado, ou nada se ele não for Ed25519.
fn chave_ed25519(certificado: &CertificateDer<'_>) -> Option<[u8; 32]> {
    let analisado = rustls::server::ParsedCertificate::try_from(certificado).ok()?;
    let spki = analisado.subject_public_key_info();
    let bytes: &[u8] = spki.as_ref();
    // Com ou sem a SEQUENCE de fora: o que importa é o algoritmo e a chave.
    let resto = bytes
        .strip_prefix(&SPKI_ED25519[..])
        .or_else(|| bytes.strip_prefix(&SPKI_ED25519[2..]))?;
    resto.try_into().ok()
}

/// Confere que a chave do certificado é a do código esperado, e delega ao

/// Um servidor QUIC cru com esta identidade, e o que ele viu: `true` se uma
/// conexão chegou a abrir um fluxo.
async fn servidor_cru(identidade: Identity) -> (SocketAddr, tokio::task::JoinHandle<bool>) {
    let _ = rustls::crypto::ring::default_provider().install_default();
    let config = seele_server::tls::server_config(identidade).expect("config do servidor");
    let ponta = quinn::Endpoint::server(config, SocketAddr::from(([127, 0, 0, 1], 0)))
        .expect("subir o servidor cru");
    let endereco = ponta.local_addr().expect("o endereço do servidor cru");
    let visto = tokio::spawn(async move {
        let Some(chegando) = ponta.accept().await else {
            return false;
        };
        let Ok(conexao) = chegando.await else {
            return false;
        };
        let Ok((_, mut recebe)) = conexao.accept_bi().await else {
            return false;
        };
        let mut oi = [0_u8; 2];
        recebe.read_exact(&mut oi).await.is_ok() && &oi == b"oi"
    });
    (endereco, visto)
}

/// Liga para `endereco` com este verificador e manda «oi» num fluxo.
async fn ligar(endereco: SocketAddr, verificador: Arc<ConfereCodigoDeTeste>) -> anyhow::Result<()> {
    let mut ponta = quinn::Endpoint::client(SocketAddr::from(([127, 0, 0, 1], 0)))?;
    ponta.set_default_client_config(cliente(verificador));
    let conexao = ponta.connect(endereco, seele_server::tls::NOME_DA_SALA)?.await?;
    let (mut envio, _) = conexao.open_bi().await?;
    envio.write_all(b"oi").await?;
    envio.finish()?;
    // O servidor lê antes de a conexão cair.
    tokio::time::sleep(Duration::from_millis(200)).await;
    Ok(())
}
```

```rust
    ///
    /// **Determinística, byte a byte**, e é por isso que ela existe em vez de
    /// [`Self::self_signed`]. O nome, o número de série e a validade são fixos,
    /// e a assinatura Ed25519 é determinística. Então o DER sai igual a cada
    /// abertura, e o dono nunca lê «A CHAVE MUDOU» ao entrar na própria sala.
    /// O DER é formato congelado: ver o vetor de `tests/identidade_da_sala.rs`.
    ///

    /// «sem data de expiração»: quem confere a sala é o código, e não a data.
    ///
    /// A semente fica só aqui, dentro do processo. Ela nunca passa pela webview
    /// e nunca vai para o banco: ver [`crate::ServerConfig::identidade`].
    ///
    /// # Errors
    ///
    /// Falha se o `rcgen` recusar a chave ou o certificado. Com 32 bytes
    /// quaisquer, isso não acontece.
    pub fn da_semente(semente: &[u8; 32]) -> Result<Self> {
        let mut pkcs8 = Vec::with_capacity(PREFIXO_PKCS8_ED25519.len() + semente.len());
        pkcs8.extend_from_slice(&PREFIXO_PKCS8_ED25519);
        pkcs8.extend_from_slice(semente);
        let der = rustls::pki_types::PrivatePkcs8KeyDer::from(pkcs8);

        let par = rcgen::KeyPair::from_pkcs8_der_and_sign_algo(&der, &rcgen::PKCS_ED25519)
            .context("o rcgen recusou a chave da sala")?;
        let mut params = rcgen::CertificateParams::new(vec![NOME_DA_SALA.to_owned()])
            .context("o nome da sala não serve de nome de certificado")?;
        params.serial_number = Some(rcgen::SerialNumber::from_slice(&[1]));
        params.not_before = rcgen::date_time_ymd(2026, 9, 23);
        params.not_after = rcgen::date_time_ymd(9999, 12, 31);
        let mut nome = rcgen::DistinguishedName::new();
        nome.push(rcgen::DnType::CommonName, NOME_DA_SALA);
        params.distinguished_name = nome;
        let certificado = params
            .self_signed(&par)
            .context("o rcgen não assinou o certificado da sala")?;

        Ok(Self {
            chain: vec![certificado.der().clone()],
            key: PrivateKeyDer::Pkcs8(der),
        })
    }
```

```rust
//!
//! Spec de 23/09, «A campainha», e o ADR 0059. É a irmã de
//! [`crate::portaria`] para a sala pessoal, e o contrário dela numa coisa: a
//! portaria foi desenhada para «nada espera» (ADR 0030), e a campainha existe
//! para **segurar** quem liga enquanto o app de quem recebe toca.
//!
//! # Só a decisão
//!
//! Nada aqui lê relógio, abre conexão ou manda mensagem. O instante entra por
//! parâmetro, no molde de [`crate::taxa`], e cada mudança volta como valor
//! para quem chamou: a sessão segura a conexão e manda a razão (o aperto em
//! três fases), e a hospedagem avisa o app (`Tocou` e `ParouDeTocar`). É o
//! que deixa provar cada desfecho sem um único `sleep`.
//!
//! # A chave de cada ligação
//!
//! A chave pública de quem liga, crua. O código e a impressão saem dela, e a
//! deduplicação é por ela: os candidatos da corrida (ADR 0037) chegam com a
//! mesma chave e não podem virar três toques.
//!
//! # Por ligação
//!
//! Uma aprovação vale para esta ligação. [`Campainha::desligar`] apaga todas,
//! e quem estava dentro recebe `ChamadaEncerrada`. Quem cai e volta em até
//! [`TOLERANCIA_DE_RECONEXAO`] entra sem tocar de novo.

///
/// Além disso, quem liga recebe `RateLimited` («muita gente ligando agora;
/// tente de novo»). Uma faixa de toque com dez nomes não é uma pergunta que

/// Um toque, do começo ao fim. Uma chave que liga de novo enquanto toca ganha
/// um número novo, e o velho deixa de existir.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct IdDoToque(u64);

/// Uma ligação tocando agora.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Toque {
    /// Qual toque.
    pub id: IdDoToque,
    /// A chave de quem liga.
    pub chave: Chave,
    /// O código dela, que é a prova. O apelido é só o que a pessoa diz.

    comecou: Instant,
}

/// O que fazer com quem acabou de chegar.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Chegada {
    /// Toca: a sessão manda `Tocando` e segura a conexão até um desfecho.
    Toca {
        /// O toque desta conexão.
        toque: IdDoToque,
        /// O toque da mesma chave que esta conexão substituiu, e cuja conexão
        /// a sessão fecha. Não é um desfecho: a mesma pessoa continua tocando.
        substituiu: Option<IdDoToque>,
    },
    /// Entra sem tocar: é quem recebe, ou quem já foi atendido nesta ligação.
    Entra,
    /// Não toca, e a sessão manda a razão.
    Recusada(Recusa),
}

/// Por que alguém não chegou a tocar.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Recusa {
    /// Está bloqueado na agenda de quem recebe.
    Bloqueado,
    /// Foi recusado há menos de [`ESPERA_DEPOIS_DE_RECUSA`].
    AcabouDeRecusar,
    /// Já há [`TOQUES_PENDENTES`] tocando.
    MuitosTocando,
    /// A ligação já tem [`TETO_DA_LIGACAO`] pessoas.
    Cheia,
}

impl Recusa {
    /// A razão que vai no `Disconnecting`.
    ///
    /// O bloqueado lê «RECUSOU», e não «bloqueado»: a spec de 23/09 não conta
    /// a quem liga que foi bloqueado.
    #[must_use]
    pub const fn razao(self) -> DisconnectReason {
        match self {
            Self::Bloqueado => DisconnectReason::ChamadaRecusada,
            Self::AcabouDeRecusar | Self::MuitosTocando => DisconnectReason::RateLimited,
            Self::Cheia => DisconnectReason::ServerFull,
        }
    }
}

/// Como um toque acabou.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Desfecho {
    /// Quem recebe atendeu: a sessão segue para a fase 3.
    Atendida,
    /// Quem recebe recusou, ou bloqueou quem tocava.
    Recusada,
    /// O prazo venceu.
    NaoAtendida,
    /// Quem ligava desistiu: a conexão fechou.
    Cancelada,
    /// Atendida, mas a ligação encheu enquanto tocava.
    Cheia,
}

impl Desfecho {
    /// A razão que vai no `Disconnecting`, quando vai alguma.
    ///
    /// `None` em [`Self::Atendida`], que segue, e em [`Self::Cancelada`], em
    /// que já não há a quem mandar.
    #[must_use]
    pub const fn razao(self) -> Option<DisconnectReason> {
        match self {
            Self::Atendida | Self::Cancelada => None,
            Self::Recusada => Some(DisconnectReason::ChamadaRecusada),
            Self::NaoAtendida => Some(DisconnectReason::NinguemAtendeu),
            Self::Cheia => Some(DisconnectReason::ServerFull),
        }
    }
}
```

```rust
            .into_iter()
            .partition(|toque| self.bloqueados.contains(&toque.codigo));
        self.toques = ficam;
        parados
            .into_iter()
            .map(|toque| ParouDeTocar {
                toque: toque.id,
                chave: toque.chave,
                desfecho: Desfecho::Recusada,
            })
            .collect()
    }

    pub fn chegou(&mut self, chave: Chave, apelido: &str, agora: Instant) -> Chegada {
        // Quem recebe é sempre admitido na própria sala (spec de 23/09).
        if chave == self.dono {
            return Chegada::Entra;
        }
        let codigo = Codigo::da_chave(&chave);
        if self.bloqueados.contains(&codigo) {
            return Chegada::Recusada(Recusa::Bloqueado);
        }
        if let Some(quando) = self.recusas.get(&chave).copied() {
            if agora.saturating_duration_since(quando) < ESPERA_DEPOIS_DE_RECUSA {
                return Chegada::Recusada(Recusa::AcabouDeRecusar);
            }
            self.recusas.remove(&chave);
        }
        match self.aprovadas.get(&chave).copied() {
            // Dentro, ou entrando: uma segunda conexão da mesma pessoa ocupa o
            // lugar que já era dela.
            Some(None) => return Chegada::Entra,
            Some(Some(saiu))
                if agora.saturating_duration_since(saiu) < TOLERANCIA_DE_RECONEXAO =>
            {
                if self.cheia() {
                    return Chegada::Recusada(Recusa::Cheia);
                }
                self.aprovadas.insert(chave, None);
                return Chegada::Entra;
            }
            Some(Some(_)) => {
                self.aprovadas.remove(&chave);
            }
            None => {}
        }
        if self.cheia() {
            return Chegada::Recusada(Recusa::Cheia);
        }
        let id = self.novo_id();
        if let Some(velho) = self.toques.iter_mut().find(|toque| toque.chave == chave) {
            let substituiu = velho.id;
            velho.id = id;
            velho.apelido = apelido.to_owned();
            velho.comecou = agora;
            return Chegada::Toca {
                toque: id,
                substituiu: Some(substituiu),
            };
        }
        if self.toques.len() >= TOQUES_PENDENTES {
            return Chegada::Recusada(Recusa::MuitosTocando);
        }
        self.toques.push(Toque {
            id,
            chave,
            codigo,
            apelido: apelido.to_owned(),
            comecou: agora,
        });
        Chegada::Toca {
            toque: id,
            substituiu: None,
        }
    }

    pub fn atender(&mut self, toque: IdDoToque) -> Option<ParouDeTocar> {
        let atendido = self.tirar(toque)?;
        let desfecho = if self.cheia() {
            Desfecho::Cheia
        } else {
            self.aprovadas.insert(atendido.chave, None);
            Desfecho::Atendida
        };
        Some(ParouDeTocar {
            toque,
            chave: atendido.chave,
            desfecho,
        })
    }

    pub fn recusar(&mut self, toque: IdDoToque, agora: Instant) -> Option<ParouDeTocar> {
        let recusado = self.tirar(toque)?;
        self.recusas.insert(recusado.chave, agora);
        Some(ParouDeTocar {
            toque,
            chave: recusado.chave,
            desfecho: Desfecho::Recusada,
        })
    }

    pub fn desistiu(&mut self, toque: IdDoToque) -> Option<ParouDeTocar> {
        let desistente = self.tirar(toque)?;
        Some(ParouDeTocar {
            toque,
            chave: desistente.chave,
            desfecho: Desfecho::Cancelada,
        })
    }

    pub fn vencer(&mut self, agora: Instant) -> Vec<ParouDeTocar> {
        let (vencidos, ficam): (Vec<Toque>, Vec<Toque>) = std::mem::take(&mut self.toques)
            .into_iter()
            .partition(|toque| agora.saturating_duration_since(toque.comecou) >= PRAZO_DO_TOQUE);
        self.toques = ficam;
        vencidos
            .into_iter()
            .map(|toque| ParouDeTocar {
                toque: toque.id,
                chave: toque.chave,
                desfecho: Desfecho::NaoAtendida,
            })
            .collect()
    }

    pub fn saiu(&mut self, chave: Chave, agora: Instant) {
        if let Some(estado) = self.aprovadas.get_mut(&chave) {
            *estado = Some(agora);
        }
    }

    pub fn desligar(&mut self) -> Vec<Chave> {
        let mut dentro: Vec<Chave> = self
            .aprovadas
            .drain()
            .filter_map(|(chave, estado)| estado.is_none().then_some(chave))
            .collect();
        dentro.sort_unstable();
        dentro
    }

    #[must_use]
    pub fn tocando(&self) -> &[Toque] {
        &self.toques
    }

    /// Quem recebe, mais quem está dentro ou entrando, já é o teto.
    fn cheia(&self) -> bool {
        1 + self.aprovadas.values().filter(|estado| estado.is_none()).count() >= TETO_DA_LIGACAO
    }

    fn novo_id(&mut self) -> IdDoToque {
        self.proximo = self.proximo.wrapping_add(1);
        IdDoToque(self.proximo)
    }

    fn tirar(&mut self, toque: IdDoToque) -> Option<Toque> {
        let posicao = self.toques.iter().position(|t| t.id == toque)?;
        Some(self.toques.remove(posicao))
    }
}
```

```rust
impl Agenda {
    pub fn abrir(caminho: PathBuf) -> Result<Self> {
        if let Some(pai) = caminho.parent() {
            std::fs::create_dir_all(pai)
                .with_context(|| format!("não consegui criar {}", pai.display()))?;
        }
        let contatos = std::fs::read_to_string(&caminho)
            .map(|texto| texto.lines().filter_map(ler_linha).collect())
            .unwrap_or_default();
        Ok(Self { caminho, contatos })
    }

    #[must_use]
    pub fn listar(&self) -> &[Contato] {
        &self.contatos
    }

    #[must_use]
    pub fn buscar(&self, codigo: &Codigo) -> Option<&Contato> {
        self.contatos.iter().find(|contato| contato.codigo == *codigo)
    }

    pub fn anotar_ligacao(
        &mut self,
        codigo: Codigo,
        apelido: &str,
        direcao: Direcao,
        quando: i64,
    ) -> Result<()> {
        let apelido = Some(limpo(apelido)).filter(|a| !a.is_empty());
        self.mudar(codigo, |contato| {
            contato.apelido = apelido;
            contato.visto_em = Some(quando);
            contato.direcao = Some(direcao);
        })
    }

    pub fn dar_nome(&mut self, codigo: Codigo, nome: &str) -> Result<()> {
        let nome = Some(limpo(nome)).filter(|n| !n.is_empty());
        self.mudar(codigo, |contato| contato.nome = nome)
    }

    pub fn bloquear(&mut self, codigo: Codigo, bloqueado: bool) -> Result<()> {
        self.mudar(codigo, |contato| contato.bloqueado = bloqueado)
    }

    #[must_use]
    pub fn bloqueados(&self) -> Vec<Codigo> {
        self.contatos
            .iter()
            .filter(|contato| contato.bloqueado)
            .map(|contato| contato.codigo)
            .collect()
    }

    /// Muda a linha deste código, criada vazia se não havia, e grava.
    fn mudar(&mut self, codigo: Codigo, mudanca: impl FnOnce(&mut Contato)) -> Result<()> {
        match self.contatos.iter_mut().find(|c| c.codigo == codigo) {
            Some(contato) => mudanca(contato),
            None => {
                let mut novo = Contato {
                    codigo,
                    nome: None,
                    apelido: None,
                    visto_em: None,
                    direcao: None,
                    bloqueado: false,
                };
                mudanca(&mut novo);
                self.contatos.push(novo);
            }
        }
        self.gravar()
    }

    fn gravar(&self) -> Result<()> {
        let texto: String = self
            .contatos
            .iter()
            .map(|c| {
                format!(
                    "{}\t{}\t{}\t{}\t{}\t{}\n",
                    c.codigo,
                    c.nome.as_deref().unwrap_or(""),
                    c.apelido.as_deref().unwrap_or(""),
                    c.visto_em.map_or_else(String::new, |v| v.to_string()),
                    c.direcao.map_or("", Direcao::texto),
                    u8::from(c.bloqueado),
                )
            })
            .collect();
        crate::conhecidos::escrever_privado(&self.caminho, texto.as_bytes())
            .with_context(|| format!("não consegui gravar {}", self.caminho.display()))
    }

    let mut campos = linha.split('\t');
    let codigo = Codigo::ler(campos.next()?).ok()?;
    let texto = |campo: Option<&str>| campo.map(str::to_owned).filter(|t| !t.is_empty());
    let nome = texto(campos.next());
    let apelido = texto(campos.next());
    let visto_em = campos.next().and_then(|v| v.parse().ok());
    let direcao = campos.next().and_then(Direcao::ler);
    let bloqueado = campos.next() == Some("1");
    Some(Contato {
        codigo,
        nome,
        apelido,
        visto_em,
        direcao,
        bloqueado,
    })
}

        .map(|c| if c.is_control() { ' ' } else { c })
```

```rust
impl Toque {
    #[must_use]
    pub fn novo(taxa_hz: u32) -> Self {
        Self {
            taxa_hz: taxa_hz.max(1),
            amostra: 0,
            volume: VOLUME,
        }
    }

    #[must_use]
    pub fn com_volume(self, volume: f32) -> Self {
        Self {
            volume: volume.clamp(0.0, 1.0),
            ..self
        }
    }

    pub fn proxima(&mut self) -> f32 {
        let taxa = u64::from(self.taxa_hz);
        let ciclo = (taxa * u64::from(CICLO_MS) / 1000).max(1);
        let nota = (taxa * u64::from(NOTA_MS) / 1000).max(1);
        let borda = (taxa * u64::from(BORDA_MS) / 1000).max(1);
        let no_ciclo = self.amostra % ciclo;
        self.amostra = (self.amostra + 1) % ciclo;

        let (frequencia, dentro) = if no_ciclo < nota {
            (NOTA_BAIXA_HZ, no_ciclo)
        } else if no_ciclo < 2 * nota {
            (NOTA_ALTA_HZ, no_ciclo - nota)
        } else {
            return 0.0;
        };
        // Sobe no começo da nota e desce no fim: zero nas duas pontas.
        let ate_o_fim = nota - 1 - dentro;
        let envelope = (dentro.min(ate_o_fim) as f32 / borda as f32).min(1.0);
        let segundos = dentro as f32 / self.taxa_hz as f32;
        self.volume * envelope * (2.0 * std::f32::consts::PI * frequencia * segundos).sin()
    }

    pub fn preencher<T: RawSample>(&mut self, saida: &mut [T], canais: usize) {
        for quadro in saida.chunks_mut(canais.max(1)) {
            let amostra = T::from_f32(self.proxima());
            for lugar in quadro {
                *lugar = amostra;
            }
        }
    }
}
```

```rust
/// O toque da sala pessoal tocando, numa linha de execução própria.
///
/// Uma linha própria porque `cpal::Stream` não é `Send` em toda plataforma
/// (ver [`AudioIo`]): ele nasce e morre na mesma linha, e o que sai daqui é só
/// o pedido de parar. **Abre só a saída.** Largar o `Tocador` para o som.
#[derive(Debug)]
pub struct Tocador {
    parar: Option<std::sync::mpsc::Sender<()>>,
    linha: Option<std::thread::JoinHandle<()>>,
    saida: Option<PlaybackDevice>,
}

impl Tocador {
    /// Começa a tocar o toque em laço, na saída de id `saida`, ou na padrão.
    ///
    /// # Errors
    ///
    /// As mesmas falhas de abrir a saída em [`open`]: o aparelho sumiu, não
    /// se descreve, não abre ou não começa. A entrada nunca é tocada.
    pub fn tocar(saida: Option<String>, volume: f32) -> Result<Self, DeviceError> {
        let (parar, quando_parar) = std::sync::mpsc::channel::<()>();
        let (pronto, quando_pronto) =
            std::sync::mpsc::channel::<Result<Option<PlaybackDevice>, DeviceError>>();
        let linha = std::thread::Builder::new()
            .name("seele-toque".into())
            .spawn(move || {
                let aberto = abrir_saida_do_toque(saida.as_deref(), volume);
                match aberto {
                    Ok((fluxo, descrito)) => {
                        let _ = pronto.send(Ok(descrito));
                        // Até alguém mandar parar, ou o `Tocador` cair.
                        let _ = quando_parar.recv();
                        drop(fluxo);
                    }
                    Err(erro) => {
                        let _ = pronto.send(Err(erro));
                    }
                }
            })
            .map_err(|erro| DeviceError::LinhaDoToque(erro.to_string()))?;
        match quando_pronto.recv() {
            Ok(Ok(descrito)) => Ok(Self {
                parar: Some(parar),
                linha: Some(linha),
                saida: descrito,
            }),
            Ok(Err(erro)) => {
                let _ = linha.join();
                Err(erro)
            }
            // A linha caiu sem responder: um pânico dentro do `cpal`.
            Err(_) => {
                let _ = linha.join();
                Err(DeviceError::LinhaDoToque(
                    "a linha do toque terminou sem dizer se abriu".to_owned(),
                ))
            }
        }
    }

    /// A saída que de fato abriu.
    #[must_use]
    pub fn saida(&self) -> Option<&PlaybackDevice> {
        self.saida.as_ref()
    }
}

impl Drop for Tocador {
    fn drop(&mut self) {
        if let Some(parar) = self.parar.take() {
            let _ = parar.send(());
        }
        if let Some(linha) = self.linha.take() {
            let _ = linha.join();
        }
    }
}

/// Abre só a saída, com o toque tocando nela. **Nunca** a entrada.
fn abrir_saida_do_toque(
    saida: Option<&str>,
    volume: f32,
) -> Result<(cpal::Stream, Option<PlaybackDevice>), DeviceError> {
    let host = cpal::default_host();
    let aparelho = resolve(&host, saida, Side::Output)?;
    let config = negociar(&aparelho, Side::Output)?;
    let descrito = describe(&aparelho).map(|(id, name)| PlaybackDevice {
        default: host
            .default_output_device()
            .and_then(|device| device.id().ok())
            .is_some_and(|default| default.to_string() == id),
        id,
        name,
    });
    let toque = crate::toque::Toque::novo(config.sample_rate()).com_volume(volume);
    let canais = usize::from(config.channels());
    let erros = StreamCounters::shared();
    let fluxo = match config.sample_format() {
        cpal::SampleFormat::F32 => fluxo_do_toque::<f32>(&aparelho, config.into(), toque, canais, erros),
        cpal::SampleFormat::I16 => fluxo_do_toque::<i16>(&aparelho, config.into(), toque, canais, erros),
        cpal::SampleFormat::U16 => fluxo_do_toque::<u16>(&aparelho, config.into(), toque, canais, erros),
        cpal::SampleFormat::I32 => fluxo_do_toque::<i32>(&aparelho, config.into(), toque, canais, erros),
        format => {
            return Err(DeviceError::UnsupportedSampleFormat {
                side: Side::Output,
                format,
            })
        }
    }
    .map_err(|source| DeviceError::Device {
        side: Side::Output,
        stage: Stage::Build,
        source,
    })?;
    fluxo.play().map_err(|source| DeviceError::Device {
        side: Side::Output,
        stage: Stage::Start,
        source,
    })?;
    Ok((fluxo, descrito))
}

fn fluxo_do_toque<T: RawSample + cpal::SizedSample>(
    aparelho: &cpal::Device,
    config: cpal::StreamConfig,
    mut toque: crate::toque::Toque,
    canais: usize,
    erros: Arc<StreamCounters>,
) -> Result<cpal::Stream, cpal::Error> {
    aparelho.build_output_stream(
        config,
        move |dados: &mut [T], _info: &cpal::OutputCallbackInfo| toque.preencher(dados, canais),
        retorno_de_erro(erros),
        None,
    )
}
```
