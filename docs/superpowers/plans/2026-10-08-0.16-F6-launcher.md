# F6 — O launcher por linha de servidor — plano de implementação

> **Para quem executa:** SUB-SKILL OBRIGATÓRIA: use
> superpowers:subagent-driven-development (recomendado) ou
> superpowers:executing-plans para executar este plano tarefa a tarefa. Os
> passos usam caixas (`- [ ]`) para o andamento.

**Objetivo:** o app 0.16 guarda o app mais novo de cada linha de servidor, abre
a linha certa ao entrar e ao hospedar, copia os dados da 0.15 antes de migrar
os próprios e baixa a linha legada (Servidor 0.15, servida por uma 0.15.2).
Tudo isso sai de um manifesto híbrido e acumulado que o atualizador da 0.15.1
continua lendo.

**Arquitetura:** o núcleo continua no `seele-lancador`, que é biblioteca pura,
sem rede e sem dependência do produto. Ele ganha:
- o tipo `Linha`;
- a linha e as APIs aceitas na `Unidade`;
- o `Pedido::MaisNovaDaLinha`;
- os dados por linha (`dados/servidor-<linha>`);
- o marcador `INSTALADA` com a linha e a soma do executável;
- a poda por linha, o tamanho e a remoção.

A casca (`apps/seele-app/src/versoes.rs`) passa a resolver **só pelo
`Resolvedor`**, com a lista de revogação conciliada e o manifesto guardado em
disco. O `empacotar/manifesto.py` escreve o topo no formato do Tauri e, ao lado,
`schema: 2` e `versions[]`, acumulando a partir do manifesto anterior. A 0.15.2
sai de um branch próprio (`linha/0.15`).

**Tecnologia:** Rust (crates `seele-lancador` e `seele-app`), Tauri 2.11.6 com
`tauri-plugin-updater` 2.10.1, Python 3 (`manifesto.py`), PowerShell
(`windows.ps1`), sh (`publicar.sh`) e JavaScript sem build (`ui/`).

**Spec:** `docs/superpowers/specs/2026-10-08-0.16-design.md`: o §1 inteiro e o
§2, «F6». O levantamento está em
`docs/superpowers/sdd/2026-10-08-0.16/levantamentos/F6-launcher.md`. Quem
executa lê os dois.

## Restrições globais

Estas valem para toda tarefa, e os valores são estes, exatos:

- **Branch:** `0.16/launcher`, a partir de `versao/0.16`. A 0.15.2 vai em
  `linha/0.15`, a partir de `54f542f`. Nunca commitar em `main` nem em
  `versao/0.16`.
- **Testes:** só estes:
  - `cargo test -p seele-lancador`;
  - `cargo test -p seele-app <filtro>`, ou `--test <arquivo>`;
  - `cargo test -p xtask <filtro>`.

  **Nunca** `cargo test --workspace` nem a bateria inteira, porque a porta 8384
  é disputada. O `cargo clippy -p <crate> --all-targets` pode rodar.
- **Os dados reais desta máquina são intocáveis.** Nenhum teste nem medida roda
  a cópia, a migração ou o depósito contra o `~/.config/seele` real. Usar
  sempre uma pasta temporária, com `SEELE_HOME` apontando para ela quando o
  processo for o app.
- **Proibido:** push; publicar release (inclusive a 0.15.2); mexer no
  `SEELE-RELEASES`, na VPS ou no indexador; mudar configurações do sistema.
- **Fronteiras.** A F6 é dona de:
  - `crates/seele-lancador`;
  - `apps/seele-app/src/versoes.rs`;
  - `apps/seele-app/ui/camada-versoes.js`;
  - `empacotar/manifesto.py`;
  - o pacote portátil em `empacotar/windows.ps1` e `empacotar/publicar.sh`;
  - os documentos da F6.

  Arquivos de outras frentes só recebem ganchos mínimos, agrupados num bloco
  com comentário: `main.rs`, `tela-boot.js`, `camada-servidores.js`,
  `tela-server.js`, `index.html` e `tauri.conf.json`. A F5 edita o `main.rs` em
  série, e a F1 é dona do `crates/seele-proto`. **Todo comando Tauri novo mora

  guardas de `apps/seele-app/tests/frontend.rs` leem só o `main.rs` (nome e
  parâmetros).
- **A linha de servidor tem texto canônico:**
  - `0.N` para as linhas de antes das duas numerações (`0.15`);
  - `M` para M ≥ 1 (`1`, `2`).

  A versão do servidor `1.0` e a `1.3` são ambas da linha `1`. A pasta de dados
  de uma linha é `<depósito>/dados/servidor-<linha>`, por exemplo
  `dados/servidor-0.15`. As linhas **têm** ordem (`0.15 < 1 < 2`); as versões
  de app continuam sem ordem calculada.
- **Os campos do manifesto, em JSON:**
  - `unit.protocol` (u8) e `unit.mod_api` (u32) **continuam obrigatórios**: o
    `Unidade` da 0.15.1 os exige, e sem eles a 0.15.1 recusaria o manifesto
    inteiro;

    servidor, `"1.0"` ou `"0.15"`) e `unit.mod_apis` (lista de u32, as APIs
    que o app roda).
- **`schema` = 2, para sempre.** `SCHEMA_CONHECIDO` não muda: a 0.15.1 recusa
  qualquer `schema` maior que 2.
- **O executável declarado em `versions[].platforms`:**
  - Mac: `SEELE.app/Contents/MacOS/seele-app`;
  - Windows portátil: `SEELE.exe`.

  O pacote portátil do Windows se chama `SEELE_<versão>_x64-portatil.tar.gz`. O
  topo (`platforms` do Tauri) continua apontando para o `-instalador.exe` no
  Windows, e **nunca** para o portátil.
- **As linhas 0.11 a 0.14 nunca entram no manifesto.**
- **«Linha» não aparece no texto de tela.** O ADR 0033 tirou a palavra da

- **A variável que diz «quem me abriu foi o launcher»:** `SEELE_LANCADOR=1`. O

- **O manifesto guardado** fica em `<config>/lancador/manifesto.json`, com os

- **O esquema do banco da 0.15.1 é a versão 13**, lida com

- **Commits:** em português, no estilo do `git log` (`feat:`, `fix:`, `docs:`,

Em `linha.rs`, acima dos testes:

```rust
//! A linha de servidor: o que o launcher guarda, uma de cada.
//!
//! Spec 0.16, §1: a versão do **app** (0.16, 0.16.1…) é o que o atualizador
//! oferece; a versão do **servidor** (Servidor 1.0, 1.1…) é o que o app e o
//! `seeled` falam. Um 1.x nunca quebra o fio, então toda a família 1.x é **uma
//! linha**: o launcher guarda o app mais novo dela, e a 0.16.1 substitui a 0.16.
//!
//! Antes das duas numerações, cada 0.N era uma linha própria: a 0.15 não
//! falava com a 0.14. Por isso o texto canônico tem duas formas, `0.N` e `M`.
//!
//! # Por que este tipo tem `Ord` e a `Versao` não
//!
//! A `Versao` é o identificador de uma publicação, e a ordem entre elas é do
//! manifesto (`0.10.5-1` saiu depois de `0.10.5`, e o semver diria o
//! contrário). A linha é um número nosso, sem sufixo de pré-lançamento: a 1
//! vem depois da 0.15 em qualquer leitura. É essa ordem que põe a linha mais
//! nova no topo do manifesto e no padrão da tela de hospedar.

use std::fmt;

/// A última linha de antes das duas numerações.
///
/// Até a 0.15, a versão do app e a do servidor eram uma coisa só: o app 0.15.1
/// falava o Servidor 0.15. O app 0.16 fala o Servidor 1.0, e daí em diante a
/// linha de uma versão de app só se sabe pelo manifesto (`unit.server`).
pub const ULTIMA_LINHA_SEM_NUMERACAO_PROPRIA: u32 = 15;

/// Por que um texto não serve como linha.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum LinhaInvalida {
    /// Texto vazio.
    Vazia,
    /// Não tem a forma `0.N` nem `M` (nem, para versão de servidor, `M.N`).
    Malformada {
        /// O que veio.
        texto: String,
    },
}

/// Uma linha de servidor, já conferida.
///
/// Guardada como números, e não como texto: é o que dá a ordem certa
/// (`0.9 < 0.15`, que o texto erraria) e o que impede `01` e `1` de serem duas
/// linhas.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct Linha {
    maior: u32,
    /// `Some` só na forma `0.N`.
    menor: Option<u32>,
}

impl Linha {
    /// Confere o texto canônico: `0.N` (N ≥ 1) ou `M` (M ≥ 1).
    ///
    /// # Errors
    ///
    /// [`LinhaInvalida`].
    pub fn nova(bruto: &str) -> Result<Self, LinhaInvalida> {
        if bruto.is_empty() {
            return Err(LinhaInvalida::Vazia);
        }
        let malformada = || LinhaInvalida::Malformada {
            texto: bruto.to_owned(),
        };
        let partes: Vec<&str> = bruto.split('.').collect();
        match partes.as_slice() {
            ["0", menor] => match numero(menor) {
                Some(n) if n >= 1 => Ok(Self {
                    maior: 0,
                    menor: Some(n),
                }),
                _ => Err(malformada()),
            },
            [maior] => match numero(maior) {
                Some(m) if m >= 1 => Ok(Self {
                    maior: m,
                    menor: None,
                }),
                _ => Err(malformada()),
            },
            _ => Err(malformada()),
        }
    }

    /// A linha de uma versão de servidor: `1.0` e `1.3` são da linha `1`;
    /// `0.15` é a linha `0.15`.
    ///
    /// # Errors
    ///
    /// [`LinhaInvalida`] quando o texto não é `M.N`.
    pub fn do_servidor(versao_do_servidor: &str) -> Result<Self, LinhaInvalida> {
        let malformada = || LinhaInvalida::Malformada {
            texto: versao_do_servidor.to_owned(),
        };
        let mut partes = versao_do_servidor.split('.');
        let (Some(maior), Some(menor), None) = (partes.next(), partes.next(), partes.next())
        else {
            return Err(malformada());
        };
        let (Some(maior), Some(menor)) = (numero(maior), numero(menor)) else {
            return Err(malformada());
        };
        match (maior, menor) {
            (0, 0) => Err(malformada()),
            (0, n) => Ok(Self {
                maior: 0,
                menor: Some(n),
            }),
            (m, _) => Ok(Self {
                maior: m,
                menor: None,
            }),
        }
    }

    /// A linha de uma versão de **app** publicada antes das duas numerações.
    ///
    /// `0.15.1` → `0.15`. Uma versão de app de 0.16 em diante devolve `None`: a
    /// regra acabou ali, e inventar a linha de uma 0.17 seria pior que não
    /// saber. Quem sabe é o manifesto.
    #[must_use]
    pub fn da_versao_legada_do_app(versao: &str) -> Option<Self> {
        let mut partes = versao.split(['.', '-']);
        let maior = numero(partes.next()?)?;
        let menor = numero(partes.next()?)?;
        // A terceira parte tem de existir: `0.15` é versão de servidor.
        partes.next()?;
        (maior == 0 && (1..=ULTIMA_LINHA_SEM_NUMERACAO_PROPRIA).contains(&menor)).then_some(Self {
            maior: 0,
            menor: Some(menor),
        })
    }

    /// O texto canônico, para a tela, o manifesto e o disco.
    #[must_use]
    pub fn como_texto(&self) -> String {
        match self.menor {
            Some(n) => format!("{}.{n}", self.maior),
            None => self.maior.to_string(),
        }
    }

    /// O nome da pasta de dados desta linha, dentro de `dados/`.
    ///
    /// Por **linha**, e não por versão: um conserto da linha (a 0.15.3) herda
    /// os dados da 0.15.2 sem cópia nenhuma.
    #[must_use]
    pub fn pasta_de_dados(&self) -> String {
        format!("servidor-{}", self.como_texto())
    }

    fn chave(&self) -> (u32, u32) {
        (self.maior, self.menor.unwrap_or(0))
    }
}

/// Um número decimal sem zero à esquerda: `01` não é `1`, porque dois textos
/// para a mesma linha seriam duas pastas para os mesmos dados.
fn numero(texto: &str) -> Option<u32> {
    if texto.is_empty()
        || !texto.bytes().all(|b| b.is_ascii_digit())
        || (texto.len() > 1 && texto.starts_with('0'))
    {
        return None;
    }
    texto.parse().ok()
}

impl PartialOrd for Linha {
    fn partial_cmp(&self, outra: &Self) -> Option<std::cmp::Ordering> {
        Some(self.cmp(outra))
    }
}

impl Ord for Linha {
    fn cmp(&self, outra: &Self) -> std::cmp::Ordering {
        self.chave().cmp(&outra.chave())
    }
}

impl fmt::Display for Linha {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.como_texto())
    }
}

impl serde::Serialize for Linha {
    fn serialize<S: serde::Serializer>(&self, s: S) -> Result<S::Ok, S::Error> {
        s.serialize_str(&self.como_texto())
    }
}

impl<'de> serde::Deserialize<'de> for Linha {
    fn deserialize<D: serde::Deserializer<'de>>(d: D) -> Result<Self, D::Error> {
        let bruto = String::deserialize(d)?;
        Self::nova(&bruto)
            .map_err(|erro| serde::de::Error::custom(format!("linha recusada: {erro:?}")))
    }
}
```

```rust
    /// As instalações desta linha, em ordem de nome.
    #[must_use]
    pub fn instaladas_da_linha(&self, linha: &crate::linha::Linha) -> Vec<Instalacao> {
        self.instaladas()
            .iter()
            .filter_map(|v| self.instalacao(v))
            .filter(|i| &i.linha == linha)
            .collect()
    }

    /// Deixa só a mais nova desta linha, pela ordem do manifesto, e apaga as
    /// outras instalações dela. **Nunca toca `dados/`.**
    ///
    /// Devolve o que tentou apagar, com o resultado de cada uma: no Windows
    /// uma versão aberta não se apaga, e quem chama registra e tenta de novo
    /// na próxima poda, em vez de calar. Uma instalação que o manifesto não
    /// lista não é podada: sem ordem, não há como saber se ela é a mais nova.
    #[must_use]
    pub fn podar_linha(&self, linha: &crate::linha::Linha, manifesto: &Manifesto) -> Vec<Podada> {
        let mut daqui: Vec<(usize, Versao)> = self
            .instaladas_da_linha(linha)
            .into_iter()
            .filter_map(|i| manifesto.posicao(&i.versao).map(|p| (p, i.versao)))
            .collect();
        daqui.sort_by_key(|(posicao, _)| *posicao);
        daqui
            .into_iter()
            .skip(1)
            .map(|(_, versao)| {
                let pasta = self.pasta_da_versao(&versao);
                // O marcador sai primeiro: uma remoção que pare no meio deixa
                // uma instalação incompleta, que a próxima instalação varre, e
                // não uma «instalada» sem metade dos arquivos.
                let resultado = std::fs::remove_file(pasta.join(MARCADOR))
                    .and_then(|()| std::fs::remove_dir_all(&pasta))
                    .map_err(|erro| erro.to_string());
                Podada { versao, resultado }
            })
            .collect()
    }
```

```rust
    /// A linha já tem o diretório dela, inteiro. Nada a fazer.
    Propria,
    /// Começa vazia.
    Nova,
}

/// O que vai acontecer com os dados, antes de acontecer.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PlanoDeDados {
    pub linha: Linha,
    pub diretorio: PathBuf,
    pub origem: OrigemDosDados,
    /// As outras linhas com dados nesta máquina, da mais nova para a mais velha.
    pub outras_com_dados: Vec<Linha>,
    /// O campo é a frase: esta linha começa vazia **e** há conversa em outro
    /// lugar — noutra linha do depósito, ou na pasta do próprio app.
    pub perde_conversas: bool,
}

/// O que uma semeadura fez.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Semeadura {
    /// A linha já tinha os dados dela, e nada foi copiado.
    JaTinha,
    /// Copiada, com o tamanho, para o rastro dizer quanto custou.
    Semeada { arquivos: u64, bytes: u64 },
}

impl Deposito {
    #[must_use]
    pub fn tem_dados_da_linha(&self, linha: &Linha) -> bool {
        self.pasta_de_dados_da_linha(linha).join(MARCADOR).is_file()
    }

    #[must_use]
    pub fn linhas_com_dados(&self) -> Vec<Linha> {
        let mut achadas = Vec::new();
        let Ok(entradas) = std::fs::read_dir(self.raiz().join("dados")) else {
            return achadas;
        };
        for entrada in entradas.flatten() {
            let nome = entrada.file_name();
            let Some(texto) = nome.to_str().and_then(|n| n.strip_prefix("servidor-")) else {
                continue;
            };
            let Ok(linha) = Linha::nova(texto) else { continue };
            if self.tem_dados_da_linha(&linha) {
                achadas.push(linha);
            }
        }
        achadas.sort_by(|a, b| b.cmp(a));
        achadas
    }

    /// O que aconteceria com os dados desta linha. **Não toca em disco.**
    ///
    /// `conversas_fora_do_deposito` é o que só a casca sabe: a pasta do próprio
    /// app (a da linha que está aberta) tem conversa?
    #[must_use]
    pub fn plano_da_linha(&self, linha: &Linha, conversas_fora_do_deposito: bool) -> PlanoDeDados {
        let outras_com_dados: Vec<Linha> =
            self.linhas_com_dados().into_iter().filter(|l| l != linha).collect();
        let origem = if self.tem_dados_da_linha(linha) {
            OrigemDosDados::Propria
        } else {
            OrigemDosDados::Nova
        };
        let perde_conversas = origem == OrigemDosDados::Nova
            && (conversas_fora_do_deposito || !outras_com_dados.is_empty());
        PlanoDeDados {
            linha: linha.clone(),
            diretorio: self.pasta_de_dados_da_linha(linha),
            origem,
            outras_com_dados,
            perde_conversas,
        }
    }

    /// Executa o plano. Para `Nova`, prepara a pasta e só então a marca.
    ///
    /// # Errors
    ///
    /// Falha de disco.
    pub fn aplicar(&self, plano: &PlanoDeDados) -> std::io::Result<EstadoDosDados> {
        if plano.origem == OrigemDosDados::Nova {
            apagar_o_resto(&plano.diretorio)?;
            std::fs::create_dir_all(&plano.diretorio)?;
            marcar(&plano.diretorio, &plano.linha)?;
        }
        Ok(EstadoDosDados {
            plano: plano.clone(),
            diretorio: plano.diretorio.clone(),
        })
    }

    /// Copia `origem` para os dados desta linha, deixando de fora os nomes de
    /// primeiro nível em `deixar_de_fora`, e marca a cópia como inteira **por
    /// último**.
    ///
    /// É a primeira abertura da 0.16 (spec 0.16, §1): os dados da 0.15 viram
    /// os da linha 0.15 **antes** de a 0.16 migrar a pasta dela. A origem é a
    /// pasta do app, e o depósito mora dentro dela; por isso o «deixar de
    /// fora», e por isso a recusa quando o destino cai dentro da origem por
    /// um caminho que não foi deixado de fora: seria uma cópia que entra em si
    /// mesma.
    ///
    /// # Errors
    ///
    /// `InvalidInput` na recusa acima; falha de disco no resto. Uma cópia
    /// interrompida não passa por dados: sem marcador, a próxima recomeça.
    pub fn semear_linha(
        &self,
        linha: &Linha,
        origem: &Path,
        deixar_de_fora: &[&str],
    ) -> std::io::Result<Semeadura> {
        if self.tem_dados_da_linha(linha) {
            return Ok(Semeadura::JaTinha);
        }
        let destino = self.pasta_de_dados_da_linha(linha);
        if let Ok(dentro) = destino.strip_prefix(origem) {
            let primeiro = dentro
                .components()
                .next()
                .and_then(|c| c.as_os_str().to_str())
                .unwrap_or_default();
            if !deixar_de_fora.contains(&primeiro) {
                return Err(std::io::Error::new(
                    std::io::ErrorKind::InvalidInput,
                    format!("o destino {} fica dentro da origem e não foi deixado de fora", destino.display()),
                ));
            }
        }
        apagar_o_resto(&destino)?;
        std::fs::create_dir_all(&destino)?;
        let mut contagem = (0_u64, 0_u64);
        copiar(origem, &destino, true, deixar_de_fora, &mut contagem)?;
        marcar(&destino, linha)?;
        Ok(Semeadura::Semeada {
            arquivos: contagem.0,
            bytes: contagem.1,
        })
    }
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum FalhaAoRemover {

}

    }

    /// Apaga a instalação desta versão. **Nunca toca os dados**: as conversas
    /// são da linha, e outro app da mesma linha as abre.
    ///
    /// # Errors
    ///
    /// [`FalhaAoRemover`].
    pub fn remover(&self, versao: &Versao) -> Result<u64, FalhaAoRemover> {
        if !self.esta_instalada(versao) {
            return Err(FalhaAoRemover::NaoInstalada);
        }
        let pasta = self.pasta_da_versao(versao);
        let tamanho = tamanho_da_arvore(&pasta);

        std::fs::remove_file(pasta.join(MARCADOR))
            .and_then(|()| std::fs::remove_dir_all(&pasta))
            .map_err(|erro| FalhaAoRemover::NaoRemovi {
                detalhe: erro.to_string(),
            })?;
        Ok(tamanho)
    }
}

/// O tamanho de uma árvore, sem seguir ligação simbólica.
fn tamanho_da_arvore(caminho: &Path) -> u64 {
    let Ok(meta) = std::fs::symlink_metadata(caminho) else {
        return 0;
    };
    if meta.is_file() {
        return meta.len();
    }
    if !meta.is_dir() {
        return 0;
    }
    std::fs::read_dir(caminho)
        .map(|d| d.flatten().map(|e| tamanho_da_arvore(&e.path())).sum())
        .unwrap_or(0)
}
```

```python
#!/usr/bin/env python3
"""Monta o `latest.json` — o manifesto que o botão de atualizar e o launcher leem.

    python3 empacotar/manifesto.py entrega v0.16.0 \
        [--repo DATA-AND-DEV/SEELE-RELEASES] [--anterior latest-anterior.json]...

… (o cabeçalho de hoje, inteiro) …

**Híbrido, desde a 0.16** (spec 2026-10-08, §1). O topo continua no formato do
`tauri-plugin-updater` — `version`, `notes`, `pub_date`, `platforms` com `url` e
`signature` —, porque é ele que o atualizador da 0.15.1 lê, e ele exige `url` e
`signature` em todo alvo do topo. Ao lado vão `schema: 2` e `versions[]`, que o
launcher lê: cada app, a linha de servidor dele, as APIs de MOD que ele roda, e
por pacote a soma e o executável.

**Acumulado.** `--anterior` é o manifesto que está publicado (o de
`releases/latest`), e o que ele lista continua listado. Sem isso, cada release
apagaria a lista das anteriores, e o launcher esqueceria o que existe.

**O `schema` nunca sobe**: a 0.15.1 recusa um manifesto de schema maior que 2.
Campo novo é acréscimo, e acréscimo não muda o número.
"""

import argparse
import datetime
import hashlib
import json
import pathlib
import re
import sys

SCHEMA = 2

# O executável de cada pacote do launcher, relativo à raiz da instalação.
# O do Mac foi medido no `.app` da 0.15.1: `CFBundleExecutable` é `seele-app`.
EXECUTAVEL_DO_MAC = "SEELE.app/Contents/MacOS/seele-app"
EXECUTAVEL_DO_WINDOWS = "SEELE.exe"

# Decisão do dono de 08/10/2026: só a linha do Servidor 0.15 continua oferecida.
LINHAS_FORA = {"0.11", "0.12", "0.13", "0.14"}

# Até a 0.15, a versão do app e a do servidor eram uma coisa só.
ULTIMA_LINHA_SEM_NUMERACAO_PROPRIA = 15


class Falha(Exception):
    """Uma recusa com frase, que vira saída 1."""


def _exigir(padrao: str, texto: str, nome: str, onde: str) -> str:
    achado = re.search(padrao, texto)
    if not achado:
        raise Falha(f"não achei {nome} em {onde}. O manifesto precisa dele para dizer o que este app fala.")
    return achado.group(1)


def servidor_legado(versao: str) -> str | None:
    """A versão do servidor de um app de antes das duas numerações: 0.15.2 → 0.15."""
    partes = re.split(r"[.-]", versao)
    if len(partes) < 3 or not (partes[0].isdigit() and partes[1].isdigit()):
        return None
    maior, menor = int(partes[0]), int(partes[1])
    if maior == 0 and 1 <= menor <= ULTIMA_LINHA_SEM_NUMERACAO_PROPRIA:
        return f"0.{menor}"
    return None


def ler_unidade(raiz: pathlib.Path, versao: str) -> dict:
    """O que este app fala, lido do código que foi compilado.

    Do código, e não de um argumento: um número digitado à mão no dia do
    release é o número que sai errado. O guarda que confere esta leitura contra
    as constantes compiladas é `a_unidade_lida_do_codigo_e_a_que_o_produto_compila`.
    """
    version_rs = raiz / "crates/seele-proto/src/version.rs"
    mods_rs = raiz / "crates/seele-proto/src/mods.rs"
    texto_version = version_rs.read_text(encoding="utf-8")
    texto_mods = mods_rs.read_text(encoding="utf-8")
    protocolo = int(_exigir(r"pub const PROTOCOL_VERSION: u8 = (\d+);", texto_version, "PROTOCOL_VERSION", str(version_rs)))
    api = int(_exigir(r"pub const MOD_API_VERSION: u32 = (\d+);", texto_mods, "MOD_API_VERSION", str(mods_rs)))
    lista = _exigir(r"pub const APIS_ACEITAS: &\[u32\] = &\[([^\]]*)\];", texto_mods, "APIS_ACEITAS", str(mods_rs))
    apis = sorted(int(n) for n in re.findall(r"\d+", lista))
    achado = re.search(r'pub const VERSAO_DO_SERVIDOR: &str = "(\d+\.\d+)";', texto_version)
    servidor = achado.group(1) if achado else servidor_legado(versao)
    if servidor is None:
        raise Falha(
            f"não achei VERSAO_DO_SERVIDOR em {version_rs}, e {versao} é de depois das duas numerações. "
            "Sem a versão do servidor o launcher não sabe a que linha este app pertence."
        )
    return {"protocol": protocolo, "mod_api": api, "server": servidor, "mod_apis": apis}


def linha_de(servidor: str) -> str | None:
    """A linha de uma versão de servidor: 1.0 e 1.3 → 1; 0.15 → 0.15."""
    achado = re.fullmatch(r"(\d+)\.(\d+)", servidor or "")
    if not achado:
        return None
    maior, menor = int(achado.group(1)), int(achado.group(2))
    if maior == 0:
        return f"0.{menor}" if menor >= 1 else None
    return str(maior)


def ordem_da_linha(linha: str) -> tuple[int, int]:
    partes = linha.split(".")
    return (int(partes[0]), int(partes[1]) if len(partes) > 1 else 0)


def linha_da_entrada(entrada: dict) -> str | None:
    return linha_de(((entrada.get("unit") or {}).get("server")) or "")


def para_o_atualizador(nome: str) -> list[str]:
    if nome.endswith(".app.tar.gz"):
        return alvos_do_mac(nome)
    if nome.endswith(".exe"):
        return ["windows-x86_64"]
    if nome.endswith(".deb"):
        return ["linux-x86_64"]
    return []


def para_o_launcher(nome: str) -> list[tuple[str, str]]:
    """Os pacotes que se abrem **ao lado** de outro, com o executável de cada um.

    O `.exe` do Windows instala por cima da instalação única, e o `.deb` instala
    no sistema: nenhum dos dois serve ao launcher. O portátil serve.
    """
    if nome.endswith(".app.tar.gz"):
        return [(alvo, EXECUTAVEL_DO_MAC) for alvo in alvos_do_mac(nome)]
    if nome.endswith("-portatil.tar.gz"):
        return [("windows-x86_64", EXECUTAVEL_DO_WINDOWS)]
    return []


def juntar_anteriores(caminhos: list[pathlib.Path]) -> tuple[list[dict], dict | None, dict | None]:
    """As versões, o topo e a lista de revogação dos manifestos anteriores."""
    versoes: list[dict] = []
    topo = None
    revogacoes = None
    for caminho in caminhos:
        dados = json.loads(caminho.read_text(encoding="utf-8"))
        if dados.get("schema") != SCHEMA or not isinstance(dados.get("versions"), list):
            print(
                f"aviso: «{caminho}» não é um manifesto acumulado (sem schema {SCHEMA}): nada dele entra. "
                "É o caso do latest.json da 0.15.1, e a linha 0.15 entra pela 0.15.2."
            )
            continue
        if topo is None and "version" in dados and "platforms" in dados:
            topo = {chave: dados[chave] for chave in ("version", "notes", "pub_date", "platforms") if chave in dados}
        if revogacoes is None and "revocations" in dados:
            revogacoes = dados["revocations"]
        for entrada in dados["versions"]:
            if any(v.get("version") == entrada.get("version") for v in versoes):
                continue
            versoes.append(entrada)
    return versoes, topo, revogacoes


def montar(entrega: pathlib.Path, tag: str, repo: str, raiz: pathlib.Path, anteriores: list[pathlib.Path]) -> dict | None:
    versao = tag[1:] if tag.startswith("v") else tag
    unidade = ler_unidade(raiz, versao)
    linha = linha_de(unidade["server"])
    atualizador: dict[str, dict[str, str]] = {}
    launcher: dict[str, dict[str, str]] = {}

    def preferencia(caminho: pathlib.Path) -> tuple[int, str]:
        return (1 if "-instalador.exe" in caminho.name else 0, caminho.name)

    for assinatura in sorted(entrega.glob("*.sig"), key=preferencia):
        pacote = assinatura.with_suffix("")
        if not pacote.exists():
            print(f"aviso: {assinatura.name} assina um arquivo que não está aqui; ignorado.")
            continue
        alvos_do_atualizador = para_o_atualizador(pacote.name)
        alvos_do_launcher = para_o_launcher(pacote.name)
        if not alvos_do_atualizador and not alvos_do_launcher:
            print(f"aviso: não sei para que sistema serve {pacote.name}; fora do manifesto.")
            continue
        url = f"https://github.com/{repo}/releases/download/{tag}/{pacote.name}"
        sig = assinatura.read_text(encoding="utf-8").strip()
        for alvo in alvos_do_atualizador:
            atualizador[alvo] = {"url": url, "signature": sig}
        if alvos_do_launcher:
            soma = hashlib.sha256(pacote.read_bytes()).hexdigest()
            for alvo, executavel in alvos_do_launcher:
                launcher[alvo] = {"url": url, "signature": sig, "sha256": soma, "executable": executavel}

    if not atualizador and not launcher:
        return None

    agora = datetime.datetime.now(datetime.timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    notas = f"SEELE {versao}. As notas estão em https://github.com/{repo}/releases/tag/{tag}"
    nova = {"version": versao, "pub_date": agora, "notes": notas, "unit": unidade, "platforms": launcher}

    anteriores_versoes, topo_anterior, revogacoes = juntar_anteriores(anteriores)
    todas = [nova] + [v for v in anteriores_versoes if v.get("version") != versao]
    guardadas = []
    for entrada in todas:
        sua_linha = linha_da_entrada(entrada)
        if sua_linha is None:
            print(f"aviso: {entrada.get('version')} não declara linha de servidor; fora do manifesto.")
            continue
        if sua_linha in LINHAS_FORA:
            print(f"{entrada.get('version')} é da linha {sua_linha}, que deixou de ser oferecida; fora do manifesto.")
            continue
        guardadas.append(entrada)
    # Estável: dentro da linha, a ordem de publicação fica, com a nova primeiro.
    guardadas.sort(key=lambda e: ordem_da_linha(linha_da_entrada(e)), reverse=True)

    mais_nova_linha = max(ordem_da_linha(linha_da_entrada(e)) for e in guardadas)
    if ordem_da_linha(linha) == mais_nova_linha or topo_anterior is None:
        topo = {"version": versao, "notes": notas, "pub_date": agora, "platforms": atualizador}
    else:
        # Um conserto de uma linha mais velha não vira a atualização de quem
        # está na mais nova: o topo é de quem já estava lá.
        topo = topo_anterior

    manifesto = {**topo, "schema": SCHEMA, "versions": guardadas}
    if revogacoes is not None:
        manifesto["revocations"] = revogacoes
    return manifesto


def main() -> int:
    argumentos = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    argumentos.add_argument("entrega", type=pathlib.Path, help="a pasta com os arquivos do release")
    argumentos.add_argument("tag", help="a tag do release, com o «v» na frente")
    argumentos.add_argument("--repo", default="DATA-AND-DEV/SEELE-RELEASES", help="dono/repositório no GitHub")
    argumentos.add_argument("--anterior", type=pathlib.Path, action="append", default=[],
                            help="um manifesto já publicado, para acumular (pode repetir)")
    argumentos.add_argument("--raiz", type=pathlib.Path, default=pathlib.Path(__file__).resolve().parent.parent,
                            help="a raiz do código de onde este release foi compilado")
    argumentos.add_argument("--so-unidade", action="store_true", help="só imprime a unidade lida do código")
    opcoes = argumentos.parse_args()

    try:
        versao = opcoes.tag[1:] if opcoes.tag.startswith("v") else opcoes.tag
        if opcoes.so_unidade:
            print(json.dumps(ler_unidade(opcoes.raiz, versao)))
            return 0
        if not opcoes.entrega.is_dir():
            raise Falha(f"«{opcoes.entrega}» não é uma pasta.")
        manifesto = montar(opcoes.entrega, opcoes.tag, opcoes.repo, opcoes.raiz, opcoes.anterior)
    except Falha as falha:
        print(str(falha), file=sys.stderr)
        return 1

    if manifesto is None:
        print("sem nenhum .sig em " + str(opcoes.entrega) + ": este release não traz manifesto.")
        return 0
    destino = opcoes.entrega / "latest.json"
    destino.write_text(json.dumps(manifesto, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
    print(destino.read_text(encoding="utf-8"))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```rust
/// Os bytes do último manifesto aceito. É o que deixa abrir uma versão já
/// instalada sem rede (ADR 0026: nada de rede ao abrir) e o que segura a

const CATALOGO_GUARDADO: &str = "manifesto.json";

pub(crate) fn guardar_catalogo(config: &str, bytes: &[u8]) -> std::io::Result<()> {
    let raiz = raiz_do_deposito(config);
    std::fs::create_dir_all(&raiz)?;
    // Escrito ao lado e trocado de uma vez: um catálogo pela metade seria lido
    // como «nenhum», e a pessoa perderia o offline sem saber por quê.
    let provisorio = raiz.join(format!("{CATALOGO_GUARDADO}.{}", std::process::id()));

    std::fs::rename(&provisorio, raiz.join(CATALOGO_GUARDADO))
}
```

```rust
    config: &str,
    manifesto: &Manifesto,
    chave: &Chave,
    pedido: &Pedido,
    ato: Ato,
    intencao: &Intencao,
) -> Result<Lancamento, FalhaAoAbrirVersao> {
    let deposito = Deposito::em(raiz_do_deposito(config));
    // **A lista que vale é a conciliada**, e o `Resolvedor` não aceita outra:
    // `docs/versoes-lado-a-lado.md`, §1. Era o buraco que a casca deixava,
```

  ```rust
pub(crate) fn esta_versao_revogada(vigente: &Vigente, em_uso: Option<&str>) -> Option<(String, Option<String>)> {
  ```

```rust
/// Confere a lista de revogação para a versão **deste** processo, num ato.
///
/// Hospedar e entrar são os atos do ADR 0046; abrir não é. Sem catálogo
/// nenhum e sem lista guardada, passa: não há o que conferir, e trancar quem
/// nunca viu lista seria trocar uma proteção por uma porta fechada.
pub(crate) async fn conferir_esta_versao(
    config: &str,
    atualizador: Option<&Atualizador>,
    ato: Ato,
) -> Result<(), FalhaAoAbrirVersao> {
    let Some(atualizador) = atualizador else { return Ok(()) };
    let vigente = match vigente_em_memoria() {
        Some(v) => v,
        None => {
            let envelope = catalogo_para(ato, config, atualizador)
                .await
                .ok()
                .and_then(|m| m.envelope_de_revogacoes().cloned());
            let v = Deposito::em(raiz_do_deposito(config))
                .conciliar_revogacoes(envelope.as_ref(), &atualizador.chave)
                .map_err(|_| FalhaAoAbrirVersao::ListaDeRevogacaoRecusada)?;
            guardar_vigente_em_memoria(v.clone());
            v
        }
    };
    match esta_versao_revogada(&vigente, em_uso()) {
        Some((defeito, corrigida_em)) => Err(FalhaAoAbrirVersao::Revogada { defeito, corrigida_em }),
        None => Ok(()),
    }
}
```

```rust
/// Os bancos que a 0.15 escreve, relativos à pasta do app.
fn bancos_da_pasta(config: &Path) -> Vec<PathBuf> {
    let mut bancos: Vec<PathBuf> = ["seele.db", "identidade-servidor.db"]
        .iter()
        .map(|n| config.join(n))
        .filter(|c| c.is_file())
        .collect();
    if let Ok(entradas) = std::fs::read_dir(config.join("servidores")) {
        bancos.extend(entradas.flatten().map(|e| e.path().join("seele.db")).filter(|c| c.is_file()));
    }
    bancos
}

fn esquema_do_banco(caminho: &Path) -> Option<i64> {
    let banco = rusqlite::Connection::open_with_flags(caminho, rusqlite::OpenFlags::SQLITE_OPEN_READ_ONLY).ok()?;
    banco.query_row("SELECT COALESCE(MAX(version), 0) FROM schema_version", [], |l| l.get(0)).ok()

pub(crate) fn primeira_abertura(config: &str) -> DadosDaLinhaLegada {
    let config_path = Path::new(config);
    let deposito = Deposito::em(raiz_do_deposito(config));
    let Ok(linha) = Linha::nova("0.15") else { return DadosDaLinhaLegada::NaoGuardei("linha".into()) };
    if deposito.tem_dados_da_linha(&linha) {
        return DadosDaLinhaLegada::JaGuardados;
    }
    let bancos = bancos_da_pasta(config_path);
    if bancos.is_empty() {
        return DadosDaLinhaLegada::SemDadosDaLinhaLegada;
    }
    if let Some(esquema) = bancos.iter().filter_map(|b| esquema_do_banco(b)).max() {
        if esquema > ESQUEMA_DA_0_15 {
            return DadosDaLinhaLegada::BancoJaMigrado { esquema };
        }

    let inicio = std::time::Instant::now();
    match deposito.semear_linha(&linha, config_path, &["lancador"]) {
        Ok(seele_lancador::Semeadura::Semeada { arquivos, bytes }) => {

        Err(erro) => {
            tracing::warn!(%erro, "não guardei os dados da 0.15");
            DadosDaLinhaLegada::NaoGuardei(erro.to_string())
        }
    }
}
```

```rust
    config: &str,
    chave: Option<&Chave>,
    versao_do_link: Option<&str>,
    propria: Option<Linha>,
) -> ParaEntrar {
    let Some(v) = versao_do_link else { return ParaEntrar::NaoSabe };
    let manifesto = chave.and_then(|c| catalogo_guardado(config, c));
    // `M.N` é versão de servidor (item 22 do contrato); `M.N.P`, de app (os
    // links de hoje).
    let linha = Linha::do_servidor(v).ok().or_else(|| match &manifesto {
        Some(m) => m.linha_da_versao_do_app(v),
        None => Linha::da_versao_legada_do_app(v),
    });

    if linha == propria {
        return ParaEntrar::Aqui;
    }

        return ParaEntrar::Baixar { linha: linha.como_texto(), tem_pacote: false, perde_conversas: false };
```
