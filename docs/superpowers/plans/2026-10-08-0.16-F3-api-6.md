# A API 6 de MODs (F3 da 0.16) — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** levar o app 0.16 a rodar só a API 6 de MODs — regiões, `pessoa.capa`, camadas, retrato projetado, eventos da tela e núcleo de confiança testado —, com os limites medidos e o `api/v6.json` congelado por último.

**Architecture:** o MOD continua fora da janela (QuickJS nativo, ADR 0049) e declara; o produto monta. A API 6 estende o mecanismo de hoje — `PONTOS_DE_CONTRIBUICAO`, `CONTEINERES_DOS_PONTOS`, `NOMES_DOS_PONTOS`, o roteador `atenderOMod` e o prelúdio de `executor.rs` — em vez de criar um segundo. Cada tarefa traz o teste que falha antes e a prova por reversão. As constantes (`APIS_ACEITAS`, `MOD_API_VERSION`) sobem só na última tarefa.

**Tech Stack:** Rust (`seele-proto`, `seele-server`, `seele-app`, `xtask`), JavaScript sem framework em `apps/seele-app/ui/` (ADR 0019), bancadas Node em `apps/seele-app/bancada/`, guardas de texto em `apps/seele-app/tests/frontend.rs`.

**Spec:** `docs/superpowers/specs/2026-10-08-api-6-rascunho.md` (o rascunho da API 6, com o `.json` ao lado), que implementa o §2 F3 e F4 e o §3 de `docs/superpowers/specs/2026-10-08-0.16-design.md`, e a Parte II de `docs/superpowers/specs/2026-09-23-sala-pessoal-por-codigo-design.md`. Os números da medição vão em `docs/adr/0056-mods-na-tela-inteira.md`.

```rust
#[test]
fn a_casca_confere_as_mesmas_capacidades_que_o_nucleo() {
    // O comentário de `CAPACIDADES_POR_API` (base.js) citava este teste desde
    // 26ad0c2, e ele não existia: o `git log -S` só achava o comentário.
    let rust = read("../../crates/seele-proto/src/mods.rs");
    let casca = without_comments(&read("ui/base.js"));
    let corpo = rust
        .split_once("pub fn capacidades_da_api(api: u32)")
        .and_then(|(_, resto)| resto.split_once("_ => &[]"))
        .map(|(corpo, _)| corpo.to_owned())
        .expect("`capacidades_da_api` mudou de forma em seele-proto");
    let espelho = casca
        .split_once("const CAPACIDADES_POR_API = Object.freeze({")
        .and_then(|(_, resto)| resto.split_once("});"))
        .map(|(corpo, _)| corpo.to_owned())
        .expect("`CAPACIDADES_POR_API` sumiu de base.js");
    // `5 => &[ "regiao", … ],` — o número de cada braço é o último termo antes
    // de `=> &[`, e os nomes vão até o `]`.
    let pedacos: Vec<&str> = corpo.split("=> &[").collect();
    assert!(pedacos.len() > 1, "`capacidades_da_api` sem nenhum braço");
    for par in pedacos.windows(2) {
        let (antes, braco) = (par[0], par[1]);
        let api = antes
            .split_whitespace()
            .last()
            .expect("um braço sem número");
        let nomes: Vec<&str> = braco
            .split(']')
            .next()
            .unwrap_or("")
            .split(',')
            .map(|n| n.trim().trim_matches('"'))
            .filter(|n| !n.is_empty())
            .collect();
        let linha = espelho
            .split_once(&format!("{api}: Object.freeze(["))
            .and_then(|(_, resto)| resto.split_once(']'))
            .map(|(lista, _)| lista.to_owned())
            .unwrap_or_else(|| panic!("a casca não tem a API {api} que o núcleo tem"));
        let da_casca: Vec<&str> = linha
            .split(',')
            .map(|n| n.trim().trim_matches('"'))
            .filter(|n| !n.is_empty())
            .collect();
        assert_eq!(
            nomes, da_casca,
            "a API {api} tem capacidades diferentes no núcleo e na casca: o anfitrião \
             recusaria o que o prelúdio ofereceu, ou aceitaria o que ele escondeu"
        );
    }
}
```
