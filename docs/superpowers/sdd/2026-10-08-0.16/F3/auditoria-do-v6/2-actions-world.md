# Auditoria do `api/v6.json` contra o produto — frente 2: `actions`, `own`, `world`, `sentido`

Ramo `0.16/api-6-corte`, ponta `48b6a1ba`. Só leitura; nenhum `cargo` rodado.

**Onde roda cada prova** (conferido em `.github/workflows/ci.yml` e em `BANCADAS` de `xtask/src/check_runtime.rs`):

- «cargo test» = `cargo test --workspace` no CI (três sistemas). Nenhum dos testes citados está sob `#[ignore]` ou `cfg(windows)`.
- «BANCADAS» = Node puro, `cargo xtask check-runtime` (job `bancadas-de-mod`): `contribuicoes-e-camadas`, `retrato-projetado`, `eventos-da-tela`, `regiao-do-mod`, `imagens-por-volume`, `continuacao-de-midia`, `envio-de-imagens`, `ponte-web`, `ciclo-do-executor`…
- «CI-nav» = bancada de navegador com passo próprio no job `bancadas`: `camadas`, `tema-do-servidor`, `regioes-do-produto`, `palco-da-chamada`, `diagnostico-de-mods`, `capa`, `nucleo`, `avatares-do-mod`…
- «check-api» = `cargo xtask check-api` (CI). Para `actions`, ele só confere que o símbolo da direita **está definido**; para `own`/`world`, também que o nome da esquerda é exposto pelo runtime (`nomes_de_servidor`, `xtask/src/check_api.rs:646`). É guarda de existência, e não de funcionamento.
- **Não roda no CI**: `tools/bancada-do-celular.py` (nenhum workflow nem xtask o chama).

**Critério usado.** PROVADA quando cada elo *próprio* da promessa (o método do prelúdio, o braço do roteador `atenderOMod`, a função que faz o efeito) tem um teste que roda e reprovaria se o elo sumisse. Numa entrada de `sentido` com várias cláusulas, o estado é o da pior cláusula, e a nota diz qual.

## Achado transversal: o prelúdio e o roteador não estão amarrados

O tipo de mensagem que o prelúdio emite (`pedir('superficie-mostrar', …)`, `crates/seele-motor/src/preludio.rs`) e o `case` do roteador (`base.js`, `atenderOMod`) são escritos à mão nos dois lados, e as bancadas mandam ao roteador a string que o autor digitou. Só **cinco** tipos são conferidos rodando o prelúdio: `superficie-criar`, `superficie-atualizar`, `formulario-erros`, `tema` (`executor.rs`) e `enviar-imagem` (`imagens-por-volume.cjs`). Para os outros quinze (`pedido`, `retrato`, `pedaco`, `soltar-arquivo`, `superficie-montar`/`classes`/`mostrar`/`ocultar`/`suja`/`titulo`/`fechar`/`descartar`, `contribuir`, `revogar-contribuicao`, `atualizar-contribuicao`), trocar a string num só dos lados não reprova nada: o método continua existindo (o `mod_de_referencia.rs` só confere o nome do membro), e o MOD recebe «a API de MODs não conhece …». Não rebaixei as entradas por isso (o que some reprova; o que diverge, não), mas um guarda de texto — todo `pedir('X'` do `PRELUDIO` tem `case "X"` no `atenderOMod`, e vice-versa, menos `snapshot`, `regiao` e `cartoes` — fecharia os quinze de uma vez.
